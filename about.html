About

A small, honest MT5 tool library

This site publishes MetaTrader 5 Expert Advisors and indicators that are free to download and free to use. It is a static website: the catalogue, the files and the documentation all live in one public GitHub repository.

How it works

Each tool is a folder containing a product.json description, the compiled MT5 file, an optional screenshot and optional documentation. A build step scans those folders and writes a catalogue index that the website reads in the browser. Publishing a new tool means committing a folder, nothing else.

There is no server, no database and no tracking. Search and filtering happen locally in your browser.

What free means here

  • No account, no email address, no licence key.
  • No trial period and no locked features.
  • No payment flow anywhere on the site.
  • Donations, if a link is configured, are voluntary and change nothing about the downloads.

If a tool is not published yet, its page says so instead of pretending a file exists.

Risk and disclaimers

Trading leveraged instruments carries substantial risk. These tools are provided as-is, with no warranty and no guarantee of profitability. Nothing published here is financial advice. Test everything on a demo account, understand the inputs, and never risk money you cannot afford to lose.

Contact

Bug reports, questions and tool requests go through the repository issue tracker. That keeps every answer public and searchable.

Roadmap

The site is deliberately static. Features that would need a backend, such as download counters, update notifications or licence management, are intentionally left out until they are actually needed. The product data format and the frontend are separated so they can be added later without a rewrite.
